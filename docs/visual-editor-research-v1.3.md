# Visual Editor and Competition Research for v1.3

## Executive finding

The next high-value step is a closed visual-editing loop with explicit competition policy, verifier-replayable layout repair, and mobile-specific editorial order. The project already has the correct structural primitive for magazine composition: one evidence-bound InfographicSpec, deterministic candidate ranking, responsive desktop/mobile output, semantic explanation, provenance-aware richer illustration, exact-pixel preview, deterministic critique, and image-aware critique. Creating a second Infographic Composer or a parallel page-layout engine now would duplicate authority and make provenance harder to reason about.

The competition and newsroom evidence points in the same direction. SND evaluates visual storytelling, resource use, infographics, news judgment, creative range, execution, voice, and for digital work also responsiveness, performance, browser compatibility, interactivity and accessibility.[1][2] OJA explicitly rewards quality and impact of visuals, media selection, storytelling effectiveness, originality, innovation, and work native to digital and mobile platforms.[3] Sigma puts data collection and analysis, public interest, visual and interactive storytelling, public service, and field-advancing innovation in the same evaluation frame.[4] Information is Beautiful adds impact, engagement, clarity, innovation, inclusion, effectiveness and beauty.[5] INMA similarly asks whether visual design and technology turn complex information into a clear, engaging journalistic narrative.[6]

The strongest architecture implication is therefore policy-aware art direction around one evidence graph. v1.3 implements that implication through InfographicSpec 1.2 competition profiles, explicit mobile ordering, a bounded visual-revision executor, and an independently recomputed competition preflight. A browser publication layer remains valuable later when the product needs scrollytelling, DOM semantics and cross-browser execution. It should be an output adapter over the same plan, not a competing page-authority system.

## What top competitions actually reward

The major competitions converge on six dimensions. First is factual and analytical integrity. Sigma begins with data collection and analysis in the service of journalism and public interest.[4] Information is Beautiful has long treated accuracy, reliable research, useful information flow and the ability to deepen understanding as core qualities.[7] This validates the project's choice to keep DuckDB results, claim provenance, hashes and independent verification outside the aesthetic critic.

Second is narrative focus. SND's highest publication honor is judged through visual storytelling, news judgment, execution and voice.[2] OJA asks whether visual media actually conveys the topic or event and places special emphasis on original digital/mobile storytelling.[3] Segel and Heer's peer-reviewed narrative-visualization framework reaches the same conclusion from research: successful data stories manage the balance between author-driven narrative flow and reader-driven discovery.[8] A page engine therefore needs explicit story roles, primary message and ordering, which the existing InfographicSpec already has.

Third is perceptual clarity. Cleveland and McGill established a scientific framing for graphical perception by identifying elementary perceptual tasks and ranking them by accuracy.[9] Heer and Bostock later replicated and extended graphical-perception experiments at scale, including spatial encoding, luminance contrast, rectangular area perception, chart size and grid spacing.[10] These results justify keeping chart-family and geometry decisions deterministic and testable. Visual novelty should operate above that layer rather than silently replacing accurate encodings.

Fourth is craft and memorability. Award rubrics make room for beauty, originality and creative range.[2][5] Research also warns against reducing visualization quality to minimalism. Bateman and colleagues found that, in their experiment, embellished charts did not reduce description accuracy relative to plain charts and produced significantly better long-term recall after two to three weeks, while cautioning against universalizing the result.[11] This is a useful basis for explanatory illustration and magazine art direction: embellishment can have editorial value when it supports message, recall and pacing, provided the underlying data encoding remains legible and verifiable.

Fifth is responsive, accessible execution. SND explicitly considers responsiveness, performance, browser compatibility, interactivity and accessibility for digital entries.[1] OJA rewards work native to mobile platforms.[3] Community tools make this operational. Datawrapper builds screen-reader descriptions, data download, colorblind warnings, semantic markup and keyboard navigation into its visualization workflow.[12] Observable Plot exposes ARIA labels, descriptions and decorative-mark hiding as first-class SVG options.[13] These practices support v1.3's mobile-specific reading order and suggest that accessibility metadata should eventually become a competition preflight dimension rather than a late QA item.

Sixth is eligibility and authorship policy. This is where a global `award=true` mode fails. SND47 rejects final images or video created wholly or partly by generative AI in editorial illustration, information graphics and multimedia categories, while allowing a range of AI-assisted workflow uses such as brainstorming, data operations, base code, error identification, translation, accessibility and usability work.[1] OJA's visual category, by contrast, centers digital storytelling effectiveness and innovation rather than the same blanket visual-origin prohibition.[3] Competition rules can diverge even when quality criteria overlap. Eligibility therefore belongs in a named policy profile with manual requirements and source URLs.

## What leading newsroom/community workflows imply

Reuters Graphics provides the clearest contemporary engineering signal. Its public Spectre project is a cross-browser UI audit harness that runs Playwright across routes on emulated devices and produces a browsable HTML report, screenshots, pixel diffs and an LLM triage prompt.[14] The pattern matters more than the specific tool: generated graphics should be observed in the runtime in which readers consume them, with deterministic capture and visual regression evidence. v1.2 already moved in this direction by rasterizing exact SVG output before multimodal review. A future web publication adapter should extend that idea to real browsers rather than create another composition model.

The Financial Times Visual Vocabulary demonstrates a second pattern. It offers reusable data-driven graphic examples as starting points for static graphics that are then refined in Illustrator.[15] This is a pragmatic division of labor: software supplies a tested visual grammar and designers retain art-direction freedom. It argues for a stable visual vocabulary plus bounded refinement rather than unlimited chart-type generation.

The New York Times ai2html workflow demonstrates a similar hybrid boundary between hand art direction and responsive web output. Its public changelog records multi-artboard responsiveness, CSS container-query resizing, lazy loading, text responsiveness, inline SVG support and accessibility metadata.[16] This suggests a credible future direction for explanatory and bespoke art: preserve newsroom-designed composition while exporting into a responsive, inspectable web layer. The existing rich-illustration adapter can serve as the provenance boundary for those assets.

Scrollama provides the interaction-side counterpart. It uses IntersectionObserver instead of raw scroll-event handling, built-in ResizeObserver support, sticky-position patterns and a mobile pattern that uses pixel offsets to avoid direction-change jumps.[17] If the project adds scrollytelling, these are mature defaults worth adopting. They do not justify adding an interactive engine before an editorial story needs one.

SCMP's 2026 INMA-winning Tai Po fire infographic is a useful product target because it demonstrates a dense explanatory package built around one event: the work explains how the fire started and why it spread, combining the explanatory task with a strong visual-journalism frame.[18] SND's 2026 World Best-Designed criteria similarly emphasize integrated visuals, illustration, infographics, news judgment, creative range, execution and voice.[2] The goal is coordinated art direction across multiple explanatory forms, not chart abundance.

Delayed Gratification offers the print-magazine analogue. Its long-running structure mixes long-form text, photo essays, features and infographics, and its editors describe infographics as both a way to condense information and a way to control editorial pace.[19][20] Reviews repeatedly identify double-page infographics, timelines and diagram series as recurring devices.[21] The durable lesson for an agentic newsroom is to treat page rhythm as an editorial variable. The user should be able to encounter a fast explanatory hit, an immersive spread, a source/method pause, and a deeper analytical section without losing the story spine.

## Architecture decision

No second Infographic Composer should be added in v1.3. The current composer already owns the right abstractions: editorial intent, story roles, priorities, emphasis, responsive geometry, deterministic candidate ranking and provenance-bound modules. Splitting that authority would create two systems that can disagree about ordering, hierarchy and source binding. Instead, v1.3 extends the same schema with explicit competition policy and a mobile reading order, then lets the visual critic request narrow changes that the verifier can replay.

A separate explanatory-illustration capability is still justified, but it should remain an adapter family rather than a page engine. The deterministic explainer is appropriate for schematic cutaway, exploded, anatomy and system diagrams where semantic parts and relationships matter more than painterly rendering. Rich illustration can handle bespoke vector/raster assets under origin/disclosure/provenance rules. For SND47 information graphics, the policy profile should require human-origin final illustration; for other contexts the system can retain disclosed AI-origin assets subject to current rules and editor approval.

A browser page-layout/export layer becomes worthwhile only when the product must ship HTML scrollytelling, interactive DOM semantics, embed behavior, or cross-browser fidelity. At that point the right architecture is `InfographicSpec -> web adapter -> Playwright/Spectre-style audit`, with the same claims, module IDs, hashes, alt text and source notes carried through. Browser layout should be an execution target, not a new editorial source of truth.

## v1.3 design requirements derived from evidence

The competition profile must be explicit and versioned. Every profile must preserve the source URLs and distinguish machine floors from official jury criteria. SND47 must reject generative-AI and mixed-origin rich illustrations for the information-graphics profile. Human authorship attestations, originality judgments, public-interest judgments and submission screenshots must stay manual because an agent cannot truthfully self-attest them.

The image-aware critic must remain a second editorial opinion. It may diagnose hierarchy, legibility, composition, typography, source legibility, responsive quality, illustration integration, contrast and distinctiveness, but its executable patch language must stay small. v1.3 therefore permits span, emphasis, priority, desktop-relative order and mobile-relative order. It cannot modify claims, SQL, source references, numeric values or evidence prose.

Revision evidence must be replayable by a separate verifier. A critic JSON and revision JSON signed by the same agent are insufficient. The verifier must start from the source plan, apply the allowed patches independently, compare the reconstructed plan to the stored final plan, and recompute an immutable editorial-evidence projection hash. This is the key security property added in v1.3.

Mobile requires its own editorial sequence when narrow-screen comprehension benefits from it. Responsive layout research and newsroom practice both show that mobile is an execution environment with distinct constraints rather than a simple geometric scale. v1.3 therefore stores `mobile_module_order` as an exact permutation of module IDs, while keeping desktop candidate ranking unchanged.

Competition preflight must be recomputed from final evidence. The machine pass should depend on final deterministic critic scores, final image-aware critic scores, profile-specific floors, rich-illustration origin and other machine-checkable constraints. The verifier should reject a forged stored `machine_passed=true`. Manual requirements remain visible even after machine pass.

## Next-stage priorities after v1.3

The first priority remains two real multimodal-provider qualifications on the pinned Rust/Pi/DuckDB/CairoSVG environment. The qualification should use the same story, the same controlled failure, the same evidence requirements and the same final competition profile, then compare tool failures, retries, plan revisions, wall time, token/cost metrics and the quality of bounded visual patches. This is the missing evidence needed to know whether model choice or architecture is the next bottleneck.

The second priority, conditional on real-provider traces, is a browser publication adapter. Build it only if live runs repeatedly need interactions or browser-specific repairs that SVG raster review cannot express. The initial scope should be narrow: semantic HTML/SVG, responsive breakpoints, alt/ARIA metadata, source/method disclosure, Playwright capture on a small device matrix, screenshot diff and performance/accessibility checks. Reuters Spectre, ai2html and Scrollama provide better starting patterns than a custom browser framework.[14][16][17]

The third priority is a real human-illustration workflow and optional C2PA signing. For SND-targeted work, the system needs human-authorship asset intake, crediting and review evidence. For other publisher policies, a richer illustration adapter can remain available with disclosed origin. C2PA signing should be added only when a production credential issuer and key-management model exist; storing provenance-shaped metadata is not equivalent to issuing a signed Content Credential.
