# Optimization Recommendations for v1.4

## Core diagnosis

The production substrate is already strong. v1.3.1 proves that the project can produce evidence-bound responsive pages, detect real raster defects, preserve provenance and remain within generous performance budgets. The next ceiling is set by editorial discovery and art direction rather than renderer speed or chart count.

The project should now optimize the intelligence spent before polished rendering. Award-level work needs competing editorial premises, concept invention, explicit rejection of adequate drafts, reporting-gap detection, scene-level synthesis and calibrated human preference. The existing renderer, verifier, competition policy and evidence graph should remain the foundation.

## Highest-leverage changes

### 1. Make `VisualConcept` a first-class artifact

The current pipeline moves too quickly from verified claims to modules and page composition. Add a concept artifact that describes the story-specific visual premise before layout. Require award mode to generate many concepts, reject most, and record why the winner is stronger.

### 2. Add an editorial-discovery phase

Search for the reader question, surprise, mechanism, human scale, spatial structure and missing reporting before choosing charts. Allow the pipeline to stop and request more evidence when the current source package cannot support a distinctive visual story.

### 3. Penalize semantic redundancy

Measure the incremental explanatory value of each module. Repeated confirmation of the same proposition should lose space even when rendered with different marks. Use freed page area for a new dimension such as geography, mechanism, uncertainty, historical context or human scale.

### 4. Extend one Composer with scene primitives

Keep a single page authority, but allow modules to share a visual scaffold through anchors, sidecars, annotation rails, shared coordinates, z-order, bleed, masks, crops and nested callouts. This is the smallest architectural step from a card stack toward an integrated magazine spread.

### 5. Separate factual schematic art from bespoke authored art

Keep the deterministic explainer for semantic systems. Add explicit production lanes for human vector illustration, GIS, photography, verified 3D and policy-permitted generated assets. Provenance and competition eligibility should be checked before composition.

### 6. Introduce slow award mode

Fast publishable output and award-target work should not share the same search budget. Award mode should spend more time on research, sketches, alternative concepts, pairwise comparison, restarts and human review. Killing a generic draft should count as success.

### 7. Calibrate taste with pairwise expert preference

Deterministic rubrics are excellent gates but weak optimization targets for elite aesthetics. Collect pairwise judgments from experienced designers and editors and measure which concepts are more story-specific, memorable, coherent and spatially intentional. Use those judgments to calibrate the image-aware critic.

### 8. Delay browser and 3D expansion until concept traces demand them

Interactive HTML, scrollytelling and 3D are valuable output capabilities, but they should be pulled by selected editorial concepts. Building them before the system can reliably invent strong concepts risks increasing technical range without improving editorial quality.

## Strategic priority

The project should now treat rendering as execution infrastructure and treat concept selection as the primary optimization problem. A successful v1.4 should produce fewer generic modules, more distinct concepts, stronger scene integration and better human preference while preserving all existing evidence and verification guarantees.
