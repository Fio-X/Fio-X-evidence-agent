```rust
    fn description(&self) -> &str {
        "Create charts/infographics from data"
    }
    
    fn parameters_schema(&self) -> Value {
        // chart_type, title, data, output_file
    }
    
    async fn execute(&self, params: Value) -> Result<ToolResult> {
        // 生成 HTML + Chart.js
    }
}
```

### Agent 调用流程
1. Agent 识别需要可视化
2. 调用 create_chart 工具
3. 传递 chart_type, title, data
4. 工具生成 HTML 文件
5. 返回文件路径
