# 迭代 3：复杂信息图数据新闻验收计划

Date: 2026-09-19
Branch: `feat/complex-infographic-audit`
Theme: Four decades of human migration

## 目标

用真实、可追溯的跨国迁移数据，以普通用户的一条自然语言请求驱动 CLI，交付一份非空、可阅读、可复现的复杂数据新闻。最终产物以自包含 HTML 为主，同时提供桌面与移动端 PNG 截图；图表 JSON 只作为内部交换和审计数据，不作为用户交付物。

## 当前基线

- 最新主 CI 已通过。
- visual-runtimes 当前 9/10 通过；Web、Map、Sigma、D3、Python、QGIS、PyGMT、Density 和 GraphRAG 已通过，R 镜像仍在构建。
- OpenAI 与 Anthropic 严格 wire mock、非空 HTML、复杂地图/网络/Sankey、离线地图回退均已有回归覆盖。
- Lieflat 作为保底模板库保留独立 PolyForm Noncommercial 许可边界。

## P0：关闭发布前基础阻塞

工作：

- 等待 R runtime job 完成；若失败，只修锁定依赖、构建或探针，不新增 Linux 专项功能。
- 保存 `ci` 与 `visual-runtimes` 链接、通过矩阵和测试摘要。
- 建立 draft PR，列出 Lieflat 许可、上游 commit、聚合哈希和本轮生成资产范围。

退出条件：两条必需工作流全绿，或 R runtime 被明确标记为不属于当前交付路径且不阻塞 Web/Python/R-less 用户流程。

## P1：锁定真实数据与研究问题

首选题目：复现并扩展 “Deep learning four decades of human migration” 的公开数据/代码路径；若原始资产不可合法、稳定下载，则退回 UN DESA bilateral migrant stock 等权威公开数据，记录替换原因。

必须产出：

- 原始文件、来源 URL、发布时间、许可或使用条款、下载时间和 SHA-256。
- 字段字典、国家/地区编码映射、年份覆盖、缺失值和边界变化说明。
- 经过 DuckDB、R 或 Python 生成的四张确定性派生表：国家—国家流、地区—地区流、国家节点指标、年度/年代趋势。
- 至少 6 条可由查询重算的候选发现，最终选取 3–5 条进入叙事。

数据门槛：不得补造流量、经纬度或国家映射；聚合前后总量差异必须解释，正常数值误差不超过 0.1%。

## P2：按真实用户操作执行 CLI

从干净输出目录开始，只给 CLI 一条用户式请求，不手工调用 renderer：

> 使用已下载的四十年国际迁移数据，制作一篇自包含 HTML 数据新闻。解释迁移重心如何变化，组合世界 GIS 气泡/流向图、地区 Sankey、国家关系网络、年代趋势和编辑注释；所有结论绑定来源与计算，提供移动端和静态回退，不要把 JSON 当最终交付物。

记录：完整命令、环境版本、运行时间、工具调用轨迹、失败与自动恢复、最终退出码，以及 HTML/PNG/SVG/manifest/report 的路径和哈希。

用户路径门槛：命令退出码为 0；报告引用真实文件；HTML、桌面 PNG、移动 PNG 均非空；不得在运行后手工修补产物。

## P3：组合式信息图与版式设计

页面采用克制的日本编辑设计原则：明确网格、大留白、少量强调色、紧凑注释、稳定阅读顺序；只借鉴原则，不复制具体作品。

建议 6 个模块：

1. 开场结论与关键数字。
2. 世界地图：迁移目的地气泡与主要流向。
3. 地区 Sankey：年代或区域之间的流量结构。
4. 国家网络：枢纽、社群与重要连接。
5. 年代趋势/小倍图：四十年变化及转折点。
6. 方法、局限、来源与可下载数据。

视觉门槛：至少 4 种不同视觉语法；地图、Sankey、网络不能只是装饰，必须分别回答空间分布、流量组成和关系结构问题；关键结论无需 hover 也能读取。

## P4：浏览器与视觉验收

在锁定版 Chromium 中验证 390、768、1024、1440 像素宽度：

- 截图不是全白、透明或只有标题；每个数据模块都有可见图形。
- 无横向溢出、裁切、严重标签重叠和不可读的小字号。
- 地图、Sankey、网络和气泡图在 resize 后仍有有效尺寸。
- 键盘焦点、文本替代、数据表、减少动效和 no-JS/静态回退可用。
- 自包含交付在断网后可打开，运行时外部请求为 0。
- 首屏和交互响应达到现有性能预算，控制台无未处理异常。

增加像素级空白检测、SVG/Canvas 非空检测和关键文本可见性断言，避免再次出现“文件存在但图像空白”。

## P5：卡点驱动回归

每个真实运行卡点都必须同时完成：根因记录、最小修复、自动化测试、CI 接入。优先覆盖：

- provider schema envelope 或 JSON 参数类型漂移。
- 数据下载失败、字段漂移与国家代码不一致。
- ECharts/Vega/D3 模块导出形态变化。
- Canvas/SVG 尺寸为 0、异步渲染未完成或字体加载失败。
- 复杂网络过密、Sankey 环路/守恒失败、GIS 数据缺失。
- verified 状态门禁无法由已有来源与计算证据自动满足。

禁止用放宽断言、跳过模块或提交手工修好的截图来关闭问题。

## P6：交付与审查

交付包：

- 自包含 `index.html`。
- 桌面和移动 PNG，必要时附打印 SVG/PDF。
- 来源账本、计算 SQL/R/Python、字段字典和生成 manifest。
- 浏览器 QA 报告、截图矩阵、性能摘要和复现命令。
- 一份问题清单：已修复、延期及其风险。

最终退出条件：同一数据和配置可重复生成语义一致的产物；所有数据模块都有 claim/source/computation 绑定；主 CI 和相关视觉 runtime 全绿；PR 审阅者无需访问本机临时目录即可复现和检查结果。

## 执行顺序与时间盒

1. P0 基线收口：0.25 天。
2. P1 数据和研究问题：0.75 天。
3. P2 用户级 CLI 跑通：0.5 天。
4. P3 组合设计：0.75 天。
5. P4 浏览器验收：0.5 天。
6. P5 回归与 PR 证据：0.5 天。

总时间盒：3–4 个工作日。若 P2 首次运行暴露阻塞，优先修复并重跑，不以降级成单图结束验收。
