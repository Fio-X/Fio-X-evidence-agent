Source table (optional starting points for the data source; not evidence). It covers two data shapes only. time-series: one measure over years for chosen entities. ranking: one measure across entities for one year. For any other shape (flows, geographic partitions, compositions, networks) ignore this table and work as before. You may use a row, use none, or find your own source; a source taken from this table is recorded and validated like any other, and the table never grants verified status. Take chart, dataset and indicator names from the catalog column or from the source itself, never from memory or a guess. Filter every dimension and the years so the answer stays small; a download stops at 25 MB or 30 s. In probed_at, unprobed means no maintainer probe has called the row's address yet.

| avoid | a host that refuses programs, e.g. `https://www.iea.org/countries/<country>` | HTTP 403 in 2 of 2 calls in one run | another provider; do not retry the same host |
