Source table (optional starting points for the data source; not evidence). It covers two data shapes only. time-series: one measure over years for chosen entities. ranking: one measure across entities for one year. For any other shape (flows, geographic partitions, compositions, networks) ignore this table and work as before. You may use a row, use none, or find your own source; a source taken from this table is recorded and validated like any other, and the table never grants verified status. The provider list is not exhaustive; eurostat covers European countries only. Take chart, dataset and indicator names from the catalog column or from the source itself, never from memory or a guess. Filter the dimensions and the years so the answer stays small; the eurostat rows say which key positions to fill. Fetch data rows with download_data only; it stops at 25 MB or 30 s. Use fetch_url only for the catalog column and the metadata addresses after unit: in the expect column; it cuts long text short. In probed_at, unprobed means no maintainer probe has called the row's address yet.

Reading a downloaded file with duckdb_query: one statement per call that starts with SELECT, WITH, DESCRIBE or SUMMARIZE, with no comment before it and no `;` inside it. The read-only check refuses a statement in which any of these words appears anywhere, even inside a quoted column name or a string: install, load, copy, export, import, attach, detach, create, drop, delete, update, insert, alter, call, pragma, set. Eurostat SDMX-CSV files have a column named LAST UPDATE, which holds one of those words, so select the other columns by name. Give result_budget as a JSON object, not as a quoted string.

Example names, copied from provider documentation and not probed (not recommendations): owid `life-expectancy`; worldbank `SP.POP.TOTL`; eurostat `DEMO_R_D3DENS`.
