name: browser-publication
description: Publish an approved InfographicSpec and StoryGraph as self-contained responsive HTML with functional style mapping, explicit interaction purpose, browser QA and static archival fallback.
---
The browser layer is a delivery surface, not a second editorial authority. Preserve the approved reader question, visual thesis, StoryGraph and claim bindings. Resolve a compatible functional StyleProfile before rendering; style tokens govern typography, information density, annotation policy, geometry, motion restraint, surface and interaction depth rather than acting as a cosmetic theme switch.

For scientific spatial work, validate a MapSpec first. The map must declare projection, CRS, extent, provenance-bound basemap, task scale, scale semantics and observation layers. Reject an inadequate basemap detail class, unsupported projection, ambiguous uncertainty or rainbow colour scale rather than silently rendering a misleading map.

Embed only runtimes actually used by modules. External network requests are forbidden in the final artifact. Test every declared breakpoint from a cold browser load, replay declared interactions, capture deterministic archive images and block horizontal overflow, Plotly text clipping, label collisions, browser errors or missing runtime modules. Technical load performance does not qualify a dense graph if the overview is an editorial hairball; large-network tasks require a specialist qualified renderer beyond the audited fallback threshold.
