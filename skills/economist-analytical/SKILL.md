# Economist analytical method

这是 Fio-X 的原创方法型 skill，借鉴公开的数据新闻工作方式，不复制 The
Economist 的字体、商标、固定皮肤或具体作品。

## Editorial contract

- 一张图只承担一个核心判断；如果存在两个独立判断，拆成两个有证据绑定的模块。
- 先检查读者任务和数据契约，再选择熟悉图形：排序/比较用横向条或点，变化用 slope/dumbbell，趋势用线，关系用散点；不要因为视觉新奇而换图。
- 标题写结论，不写图形名称。副标题明确时间范围、比较基准、单位和是否为估算。
- 直接标注关键数据和异常点；能放在图旁的标签不藏进图例或 hover。
- 颜色克制，只用一种强调色表达一个重点；不使用渐变、装饰阴影或无语义颜色。
- 数值轴不断轴，零基准和比例关系诚实；比较对象必须可比，混合口径要拆开并说明。
- 来源、计算、快照 hash 和 claim id 可追溯；没有经过验证的来源不能进入发布图。
- 明确可访问名称、长描述和数据表；在窄屏上保持标签与读数顺序。

## Completion signals

`title` 是完整句或判断短语，`claim_id`、来源和计算绑定齐全，核心标签无需交互即可读到，图形文件真实写入 run root，并通过桌面/移动 QA。
