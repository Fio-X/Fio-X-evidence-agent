---
name: d3-editorial
description: Build highly customized browser-native editorial visuals such as radial networks, hierarchies, circle packing, custom Sankey, chord and linked explanatory views with D3.
---
Use D3 only when a standard declarative renderer cannot express the visual thesis cleanly. Choose it for radial hierarchy/network structures, custom flow geometry, circle packing, edge bundling, bespoke annotation and linked views. The visual intent and topology must be declared before the library is selected. Bind every visible mark to verified data or an explicitly labeled schematic relationship. Production output must use the pinned local D3 runtime and cannot depend on a CDN.
